# proke frontend

Vite + React + TypeScript + Tailwind, with TanStack Router for routing and kea for state. It is a
trimmed-down copy of the cryptly frontend's shape, carrying just enough to exercise the backend's
GitHub login.

## Layout

```
src/
  routes/          file-based TanStack routes (routeTree.gen.ts is generated)
  components/
    auth/          GitHub login button + OAuth callback page
    home/          mock landing page
    ui/            shadcn-style primitives
  lib/
    api/           axios wrappers over the backend
    logics/        kea logics (*Type.ts files are generated by kea-typegen)
```

## Setup

```bash
pnpm install
cp .env.example .env
```

Then create a GitHub OAuth app (Settings -> Developer settings -> OAuth Apps) with:

| Field                    | Value                                            |
| ------------------------ | ------------------------------------------------ |
| Homepage URL             | `http://localhost:49173`                         |
| Authorization callback URL | `http://localhost:49173/app/callbacks/oauth/github` |

Put the client ID in `frontend/.env` as `VITE_GH_APP_CLIENT_ID`, and the client ID + secret in
`backend/.env` as `GH_APP_CLIENT_ID` / `GH_APP_CLIENT_SECRET`.

## Run

```bash
pnpm dev   # vite on 49173 + kea-typegen in watch mode
```

Or run the whole stack with `mprocs` from the repo root.

## Login flow

1. `/` renders the mock landing page with a **Sign in with GitHub** button.
2. The button redirects to GitHub's OAuth authorize URL.
3. GitHub redirects back to `/app/callbacks/oauth/github?code=...`.
4. That page posts the code to the backend's `POST /auth/github/login`, which returns a JWT.
5. The JWT is persisted in localStorage by `authLogic`, which then loads `GET /users/me` and the
   landing page shows the signed-in user.
